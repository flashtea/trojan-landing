## HYROX

Ein Rennformat, das weltweit nach denselben Regeln läuft: acht Kilometer Laufen im
Wechsel mit acht Kraftstationen. Vor jeder Station wird 1 km gelaufen. Einer der acht
Kurse bereitet darauf vor, zweimal pro Woche. Man kann ihn mitmachen, ohne je an den
Start zu gehen.

Die acht Stationen in dieser Reihenfolge:
1000 m SkiErg · 50 m Sled Push · 50 m Sled Pull · 80 m Burpee Broad Jumps ·
1000 m Rudern · 200 m Farmers Carry · 100 m Sandbag Lunges · 100 Wall Balls

# Technischer Rahmen

Eine einzelne HTML-Datei mit eingebettetem CSS und JS. Kein Framework, kein Build,
keine externen Anfragen ausser der Kursabfrage unten. Alles liegt lokal.

## Kurse aus dem Buchungssystem

Die echte Woche kommt aus derselben öffentlichen Schnittstelle, aus der die App bucht.
Fällt sie aus, greift ein eingefrorener Stand — eine leere Woche wäre schlimmer als
eine, die eine Woche alt ist.

```js
const PLAN_STAND=[
  [1,'06:00',75,'Performance'],   [3,'06:00',75,'Performance'],
  [0,'08:15',75,'FBB/Strength & Power'], [1,'08:15',75,'Performance'],
  [2,'08:15',75,'FBB/Strength & Power'], [4,'08:15',75,'Performance'],
  [5,'08:15',75,'FBB/Strength & Power'], [5,'09:30',75,'Community TeamWOD'],
  [4,'09:45',45,'Mama reloaded'],  [2,'10:00',45,'Mama reloaded'],
  [4,'10:45',45,'Mama reloaded'],
  [2,'16:00',75,'Powercircle'],    [4,'16:00',75,'FBB/Strength & Power'],
  [0,'17:15',75,'Powercircle'],    [0,'17:15',75,'Performance'],
  [1,'17:15',75,'FBB/Strength & Power'], [2,'17:15',75,'Team-WOD'],
  [3,'17:15',75,'Performance'],    [4,'17:15',75,'Hyrox'],
  [0,'18:30',75,'FBB/Strength & Power'], [1,'18:30',75,'Performance'],
  [2,'18:30',75,'Hyrox'],          [3,'18:30',75,'FBB'],
  [3,'18:30',75,'Powercircle']
].map(([tag,zeit,dauer,name])=>({tag,zeit,dauer,name}));   // tag: 0 = Montag

function planWoche(){
  const jetzt=new Date(), versatz=(jetzt.getDay()+6)%7;
  const mo=new Date(jetzt.getFullYear(),jetzt.getMonth(),jetzt.getDate()-versatz);
  const so=new Date(mo.getFullYear(),mo.getMonth(),mo.getDate()+7);
  const f=d=>`${d.getFullYear()}-${String(d.getMonth()+1).padStart(2,'0')}-${String(d.getDate()).padStart(2,'0')}T00:00:00.000Z`;
  return [f(mo),f(so),mo];
}

(async()=>{
  const [von,bis]=planWoche();
  try{
    const r=await fetch(`https://gymkloud.com/api/public/course-event/trojan_performance`+
      `?from=${von}&to=${bis}&groupNames=Kurse`);
    if(!r.ok) throw new Error(r.status);
    const d=await r.json();
    if(!Array.isArray(d)||!d.length) throw new Error('leer');
    zeichnen(d.map(e=>({
      tag:(new Date(e.startTime).getDay()+6)%7,
      zeit:e.startTime.slice(11,16),
      dauer:Math.round((new Date(e.endTime)-new Date(e.startTime))/60000)||75,
      name:(e.course&&e.course.name||'').trim(),
    })),true);
  }catch(_){ zeichnen(PLAN_STAND,false); }
})();
```

Der Kursname kommt aus einer fremden Quelle — vor dem Einsetzen in Markup escapen,
oder `textContent` verwenden.

## Was die Seite leisten muss

- **360 px bis 1920 px**, kein waagrechter Überlauf. Auf dem Handy entschieden — die
  Zielgruppe kommt vom Handy.
- Tippflächen mindestens 44×44 px.
- Per Tastatur bedienbar, sichtbarer Fokusring auf jedem Bedienelement.
- `@media (prefers-reduced-motion:reduce)` schaltet Bewegung ab — auch `scroll-behavior`
  und Hover-Transformationen, nicht nur die eigenen Einblendungen.
- Bilder unterhalb des ersten Bildschirms `loading="lazy"`, das Hero-Bild
  `fetchpriority="high"`.
- Ein Sprunglink zum Inhalt vor der Navigation.
- Sinnvolle `alt`-Texte; rein dekorative Bilder `alt=""`.
- `<title>` und `<meta name="description">` setzen. Das Markup beginnt mit
  `<!doctype html>` und `<html lang="de">`.
- Platzhalter-Links (`href="#"`) dürfen nicht an den Seitenanfang springen —
  `preventDefault()`.
- Das Kontaktformular hat im Entwurf keinen Empfänger. Es soll das sagen, statt so zu
  tun, als hätte es abgeschickt.
